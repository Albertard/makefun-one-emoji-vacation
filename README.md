# One Emoji, One Dream Vacation

A program that writes exactly one emoji — a desert island 🏝️ — to
`/output/entry.txt`. Built for the make.fun competition **"One Emoji,
One Dream Vacation"** (`u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35`).

## The entry

> 🏝️

One glyph, no words. A remote island with a palm tree and turquoise
water: the postcard version of a dream vacation. It beats the obvious
beach on specificity — a beach could be any weekend by the sea, while
an island is a journey, a faraway place you have to dream your way
to. And it carries the oldest daydream in the book: marooned in
paradise, on purpose.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only. The
program validates its own output against the gate (1–8 characters,
not only white space, no words) before writing it.
